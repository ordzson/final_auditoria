# Apertura con aplicaciones animadas

Capturas directas de la aplicación local compilada, tomadas con Chrome/Playwright durante el refinamiento solicitado por el usuario el 4–5 de noviembre de 2026. No son imágenes generadas, material del PDF ni evidencia del incidente.

- `sql-actividad.png`, `sql-resultado.png`, `transferencia.png`, `crm.png`, `siem.png`, `nota.png`, `recuperacion.png`: escritorio, 1280 × 720.
- `escritorio-1920.png`: transferencia, 1920 × 1080.
- `movil.png`: pantalla adaptada, 390 × 844.
- `movimiento-reducido.png`: estado estable sin desplazamiento de filas.
- `sin-webgl.png`: el mismo dibujado en canvas 2D cuando WebGL no está disponible.

Se conservaron las cifras del canon. Filas, consulta, paquetes, pasos y contadores intermedios son ilustrativos. La presentación no completa revisiones ni agrega fuentes a la auditoría.

Verificación enfocada: siete pruebas de reconstrucción; TypeScript y compilación; comprobación de avance, pausa, retroceso, separación entre actividad y enunciado, intervalo de la nota, movimiento reducido y adaptación. La batería completa de la entrega base no se repitió.

El detector visual se ejecutó una vez. Señaló colores/tamaños fuera de la documentación previa y la fuente Arial heredada de impresión. La paleta de las aplicaciones RN es una ampliación intencional solicitada por el usuario; no se declara un detector sin avisos.
